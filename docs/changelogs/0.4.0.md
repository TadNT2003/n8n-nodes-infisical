# Changelog — 0.4.0

_Compared against 0.3.8._

This release is a major expansion of **InfisicalSync** Form-mode coverage — the number of natively supported n8n credential types grows from **31 to 75** — plus a new fallback option for missing credentials and several correctness fixes in the auto-sync payload builder.

## Highlights

- **44 new Form-mode credential types** across AI, SaaS, messaging/social (token & OAuth2), source control, databases, SSH, email, and AWS. JSON mode continues to accept any type registered in n8n.
- **New "If Credential Missing" option** for both Infisical → n8n operations.
- **Fixes** for the `allOf` conditional handling that previously stripped required fields, a Jira/MSSQL field-name mismatch, a Form UI gap, and Infisical error messages arriving as objects.

## New credential types (Form mode)

### AI / LLM
- `googlePalmApi` (Google Gemini / PaLM)

### Productivity / SaaS
- `airtableTokenApi`, `notionApi`, `stripeApi`, `hubspotAppToken`, `sendGridApi`

### Messaging / Social (token)
- `slackApi`, `telegramApi`, `twilioApi`, `mattermostApi`, `matrixApi`, `rocketchatApi`, `whatsAppApi`, `facebookGraphApi`, `pushoverApi`

### Messaging / Social (OAuth2)
- `slackOAuth2Api`, `microsoftTeamsOAuth2Api`, `twitterOAuth2Api`, `twitterOAuth1Api`, `linkedInOAuth2Api`, `discordOAuth2Api`

### SaaS (OAuth2)
- `salesforceOAuth2Api`, `hubspotOAuth2Api`, `dropboxOAuth2Api`, `spotifyOAuth2Api`

> **OAuth2 note:** OAuth2 credentials sync only the app-registration fields (`clientId`/`clientSecret` and service-specific config such as Salesforce `environment` or Dropbox `accessType`). The `oauthTokenData` blob from the browser consent flow is **not** synced — a pulled credential must be re-authorised (one "Connect" click) in the target n8n.

### Source Control
- `githubApi`, `githubOAuth2Api`, `gitlabApi`, `gitlabOAuth2Api`, `bitbucketApi`, `bitbucketAccessTokenApi`

### Databases
- `crateDb`, `questDb`, `timescaleDb`, `elasticsearchApi`, `supabaseApi`, `nocoDb`, `snowflake`

> `crateDb`/`questDb`/`timescaleDb` are Postgres wire-compatible and share its host/database/user/password/port/ssl shape. `snowflake` supports both password and key-pair authentication via its `authentication` field.

### SSH
- `sshPassword`, `sshPrivateKey`

> These are the standalone SSH credential types — distinct from the SSH-tunnel sub-fields already synced inside `mySql`/`postgres`.

### Email
- `smtp`, `imap`

> `smtp` has a conditional `disableStartTls` field that only applies when `secure: false`.

### Cloud / Infrastructure (AWS)
- `aws`, `awsAssumeRole`

> Both share `region` and the seven custom VPC-endpoint overrides (gated by `customEndpoints`). `aws` supports temporary STS credentials via `temporaryCredentials`; `awsAssumeRole` assumes an IAM role via `roleArn`/`externalId` and can source its base credentials from n8n's own system credentials (`useSystemCredentialsForRole`).

## New feature — "If Credential Missing"

Both Infisical → n8n operations (**Sync from Infisical** and **Auto Sync from Infisical**) now expose an **If Credential Missing** option for when the target n8n credential can't be found (deleted since the last sync, or — for Auto Sync — never created):

- **Create New Credential** (default) — recreate it using the `n8n_credential_type` metadata tag stored on the folder's secrets.
- **Skip** — leave n8n untouched and report the item as skipped instead of creating or erroring.

## Fixes

- **`autoSyncFromInfisical` no longer deletes required credential fields.** The `allOf` / `if/then/else` schema handler mishandled vacuous-truth branches, causing Google OAuth types (`googleOAuth2Api`, `googleSheetsOAuth2Api`, `googleDriveOAuth2Api`, `googleDocsOAuth2Api`) to be rejected with HTTP 400 for missing `serverUrl` / `sendAdditionalBodyProperties` / `additionalBodyProperties`. See [vacuous-truth-fix.md](../vacuous-truth-fix.md).
- **Jira / MSSQL field-name mismatch fixed** — the `server` field is now mapped correctly.
- **Form UI gap fixed** in the supported-credentials selector.
- **Infisical error messages** that arrive as objects (rather than strings) are now handled instead of surfacing `[object Object]`.
